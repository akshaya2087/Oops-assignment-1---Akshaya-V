## 📌 Project Description
This repository contains a modular Java application demonstrating core Object-Oriented Programming (OOP) concepts in an electronics domain scenario, including class inheritance, constructor chaining using `super()`, abstract classes/methods, and custom exception handling.

---

## 📁 File Breakdown

| File Name | Description |
| :--- | :--- |
| `SmartDeviceDemo.java` | Demonstrates `Device` superclass and `SmartDevice` subclass with constructor chaining via `super()`. |
| `WarrantyDemo.java` | Demonstrates the abstract `Warranty` class and its implementation in `ExtendedWarranty`. |
| `CustomExceptionDemo.java` | Implements user-defined `InvalidWarrantyPeriodException` thrown when a negative warranty duration is passed. |

## 🚀 How to Run in IntelliJ IDEA

1. Open **IntelliJ IDEA**.
2. Select **Open** and select the root directory of this project.
3. Open any of the `.java` files from the `src/` directory.
4. Click the **Green Play Button ▶** next to `public static void main` or press `Shift + F10` (`Control + R` on Mac).
